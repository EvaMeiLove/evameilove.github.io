# Личный сайт

Персональный сайт на Next.js, React, TypeScript и Tailwind CSS. Публикация выполняется на GitHub Pages вручную.

## Содержимое

- `src/config/site.config.ts` — данные профиля, ссылки, фотографии, медиа и идентификаторы аналитики.
- `src/config/support.config.ts` — способы поддержки и желания.
- `src/translations/index.ts` — русские и английские тексты интерфейса.
- `public/images/` — исходные изображения сайта.
- `public/brand.svg` — исходная иконка; `public/og-image.jpg` — изображение для предпросмотра ссылки.

Репозиторий публичный. Не добавляйте пароли, токены, секретные ключи кошельков, фразы восстановления и личные сведения, не предназначенные для публикации. Данные остаются доступными в истории коммитов, даже если позднее удалить их из файлов.

## Разработка

Нужен Node.js 22.

```bash
npm ci
npm run dev
```

Проверка кода — `npm run lint`. Сборка для GitHub Pages — `DEPLOY_TARGET=github-pages npm run build`; результат находится в `out/`. После сборки дополнительные проверки можно запустить командой `python3 scripts/check-static.py`.

Шрифты Playfair Display и DM Sans входят в зависимости проекта и включаются в сборку. Получать их с Google Fonts при сборке не требуется.

## Публикация

В настройках репозитория в **Settings → Pages** должен быть выбран источник **GitHub Actions**. Публикация запускается вручную: **Actions → Publish site → Run workflow → main**. Workflow устанавливает зависимости, проверяет код, собирает сайт и публикует его. Коммит сам по себе публикацию не запускает.

Опция `rebuild_history` пересоздаёт историю `main` одним коммитом; для обычной публикации её следует оставлять выключенной. Пересоздание истории не удаляет внешние копии и кэшированные данные.

## Фотографии и медиа

Изображения JPEG, PNG, WebP и AVIF из `public/images/` автоматически подготавливаются перед локальным запуском и сборкой. Создаются версии WebP разного размера и размытие для предварительного показа; большие версии загружаются при открытии изображения. Добавляйте изображения в `site.config.ts` с подписями `alt` и `altEn` для русского и английского языков.

Оригиналы изображений доступны в публичном репозитории. Перед добавлением проверяйте права на публикацию и удаляйте нежелательные метаданные. Большая галерея увеличивает время и размер сборки.

YouTube-плеер загружается по нажатию; при недоступности сервиса остаётся внешняя ссылка. Обложки музыкального раздела хранятся локально.

## Поддержка и желания

В `support.config.ts` поле `enabled` управляет видимостью раздела. `wallets` содержит валюту, сеть и публичный адрес получения; `links` — дополнительные HTTPS-ссылки; `wishes` — список желаний. На сайте отображаются только заполненные способы поддержки. При добавлении криптовалюты указывайте точную сеть и проверенный адрес для этой сети.

Названия и описания желаний можно указать на двух языках. Поле `target` задаёт необязательную цель, `raised` — сумму, внесённую вручную, `currency` — код валюты, `updatedAt` — дату обновления. Шкала не отображается без положительного значения цели. Сайт не отслеживает поступления и не привязывает их к желаниям автоматически. Группы фильтров настраиваются в `src/components/Support.tsx`.

## Аналитика

Идентификаторы `yandexMetrikaId` и `googleAnalyticsId` задаются в `site.config.ts`; пустое значение отключает соответствующий счётчик. Идентификаторы являются публичными, секреты для них не нужны. Google Analytics загружается после начала работы страницы, Яндекс Метрика — с отложенной загрузкой через альтернативный CDN.

Сайт отправляет события `social_click`, `gallery_open`, `media_open`, `support_click`, `wallet_copy` и `wish_click` в подключённые системы. Параметры содержат идентификаторы элементов и тип медиа, но не адреса кошельков и не суммы. Копирование адреса или переход к оплате не подтверждают получение перевода. В Метрике для событий можно настроить цели; получение событий зависит от доступности счётчиков в браузере посетителя.

Вебвизор и соответствующие функции нужно также включить в настройках счётчика Яндекс Метрики. Настройки записи полей управляются в интерфейсе Метрики. Блокировщики и сетевые ограничения могут препятствовать загрузке счётчиков; часть коротких посещений может не попасть в отложенную аналитику.

## Иконки и предпросмотр ссылки

Перед сборкой из `public/brand.svg` создаются favicon, иконки приложения и webmanifest. При замене иконки может понадобиться увеличить версию URL в метаданных и проверить кеш браузера. Для изменения карточки ссылки замените `public/og-image.jpg`; мессенджеры могут сохранять старый предпросмотр в кеше.
